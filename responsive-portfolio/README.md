# 🌐 Harsha Prada Portfolio Website

A sleek and responsive personal portfolio website built with HTML, CSS, and JavaScript. It showcases projects, skills, contact information, and other professional details with a polished, modern design and smooth user experience.

## 🚀 Features

- Smooth animations and transitions
- Dark-themed layout with professional UI/UX
- Responsive design for all screen sizes
- Scroll-based reveal effects
- Sections included:
  - Hero / Home
  - About
  - Skills
  - Projects
  - Resume
  - Contact
- External links to GitHub, LinkedIn, and resume

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- ScrollReveal.js (for scroll animations)
- Google Fonts
- Responsive Flexbox/Grid layout
